# NetEase Cloud Music Crawler (网易云音乐爬虫)

网易云音乐歌曲爬虫，支持单曲下载和歌单批量下载。

## 功能特点

- **单曲下载**：通过歌曲 ID 下载单首歌曲
- **歌单批量下载**：通过歌单 ID 批量下载歌单内所有歌曲
- **两种下载方式**：
  - 直链方式：通过网易云音乐的公开直链下载
  - JS逆向方式：逆向分析加密参数，通过 API 接口获取真实音频地址

## 文件说明

| 文件 | 说明 |
|------|------|
| `config.py` | 配置文件，设置歌单 ID、歌曲数量、下载方式等 |
| `Spider_url.py` | 批量下载脚本，通过歌单 ID 爬取并下载所有歌曲 |
| `Spider_singleSong.py` | 单曲下载脚本，支持直链和 JS 逆向两种方式 |
| `Spider02.py` | 使用预请求参数直接下载指定歌曲 |
| `wyy.js` | CryptoJS 加密库 + 网易云 API 签名算法 |

## 环境要求

- Python 3.6+
- 依赖库：`requests`, `PyExecJS`

## 安装

```bash
pip install requests PyExecJS
```

## 使用方法

### 1. 配置

编辑 `config.py`：

```python
songListId = 123456789       # 歌单 ID（替换为你自己的）
MAX_SONG_NUMS = 10           # 下载歌曲数量上限
choice = 2                   # 1: 直链方式  2: JS逆向方式
music_id = '123456789'       # 单曲 ID
title = '歌曲名称'            # 歌曲标题
```

### 2. 获取 Cookie

由于网易云音乐接口需要登录态，你需要在浏览器中登录[网易云音乐](https://music.163.com/)，打开开发者工具（F12），从网络请求中复制你的 Cookie，替换脚本中的 `cookie` 字段。

### 3. 运行

**批量下载歌单：**

```bash
python Spider_url.py
```

**下载单曲：**

```bash
python Spider_singleSong.py
```

- 本工具仅供学习研究使用，请勿用于商业用途
- 下载的音乐文件请尊重版权，仅限个人学习使用
